## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Confirmação "1" → insert privilegiado | O "1" do usuário dispara um insert como service_role; o dono da pendência (userId resolvido por phone) é a única identidade usada. |
| webhook → wa_log_transaction_service | RPC confia em p_user_id; owner-guard interno + GRANT service_role-only são a defesa. |
| Consulta de saldo/extrato → dados do usuário | Query server-side filtra por userId; nunca expõe dados de outro usuário. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-24 | Elevation of Privilege | Insert em conta/cartão de outro usuário | high | mitigate | RPC wa_log_transaction_service com owner-guard por p_user_id (CONTA/CARTAO exception); p_user_id = dono da pendência resolvido por phone verificado no opt-in. |
