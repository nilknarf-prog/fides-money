<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Descrição do usuário (`t.desc`) → arquivo CSV | Texto livre exportado e aberto no Excel/LibreOffice |
| Dado do usuário → localStorage → `JSON.parse` no reload | Preferências de UI persistidas e reidratadas |
| Input do modal (categoria/valor) → DOM | Valores renderizados no preview de limite |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-CSV | Tampering | `handleExport` (células de descrição, categoria e conta) | mitigate | `csvSafeCell` prefixa com aspa simples TODA célula user-controlled (`t.desc`, `catLabel`, `acctName`) que começa por igual/mais/menos/arroba — neutraliza fórmula no Excel em todas as colunas editáveis pelo usuário (finding #1 [HIGH] do 09-REVIEWS; achado do 09-RESEARCH) |
| T-09-LS | Denial of Service (local) | persistência `fides:tx.state` | mitigate | `readTxState`/`writeTxState` envolvem `JSON.parse`/`localStorage` em `try{}catch(_){}` com fallback ao default — dado malformado não quebra o app |
| T-09-07 | Information Disclosure | preview de limite | accept | Só lê `categoryUsage` do próprio usuário (RLS existente via contexto); nenhuma query nova; JSX escapado, sem innerHTML |
| T-09-SC | Tampering | instalação de pacotes | accept | Nenhum pacote novo — `Blob`/`localStorage` nativos (09-RESEARCH "Standard Stack") |
</threat_model>
