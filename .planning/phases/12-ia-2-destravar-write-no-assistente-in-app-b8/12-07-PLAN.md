<objective>
Fechar o 12-UAT Test 1 (major): "lança 1 real na categoria natal, no cartão de crédito bradesco" abria o card apontando para a CONTA CORRENTE Bradesco, ignorando "cartão de crédito", quando existe uma conta e um cartão homônimos.

Causa-raiz (já diagnosticada — `.planning/debug/cartao-homonimo-vira-conta.md`, NÃO re-diagnosticar): dois defeitos convergentes empurram homônimos para a conta.
1. `resolveWriteToolArgs` (branch `lancar_transacao`, :298-346) resolve CONTA-PRIMEIRO: `findAccountByName(ref)` e só consulta `findCardByName(ref)` se NENHUMA conta casar (`const card = !acc ? findCardByName(ref) : null`), com `target: acc ? account : card`. Qualquer conta que case o nome vence; o qualificador "cartão" do usuário nunca entra na decisão. `findAccountByName` (:145-149) usa `.includes(q)` frouxo → "bradesco" casa "Conta Corrente Bradesco".
2. O schema de `lancar_transacao` (api/assistant.js :107-121) expõe só um STRING opaco `conta_ou_cartao`, sem discriminador de tipo — o modelo sabe distinguir conta de cartão (o contexto lista os dois separadamente) mas não tem canal para transmitir isso; os exemplos "Nubank/Bradesco/Inter" ainda o induzem a mandar só o nome do banco.

Duas frentes:
1. **Discriminador na tool:** adicionar `tipo_destino: enum['conta','cartao']` (opcional) a `lancar_transacao` + regra de prompt para o modelo preenchê-lo a partir das palavras do usuário ("cartão"/"crédito"/"fatura" → cartao; "conta"/"débito"/"dinheiro"/"pix" → conta).
2. **Resolver honra o tipo + desambigua homônimos:** `tipo_destino='cartao'` resolve por `findCardByName` exclusivamente (alcançando o caminho de cartão já correto: `mesFaturaFor` + status pendente); `'conta'` por `findAccountByName` exclusivamente; sem tipo e com homônimo (conta E cartão casam) → retornar erro de desambiguação pedindo qual, em vez de escolher pela ordem.

O caminho de cartão (status Pendente + `mesFaturaFor` + `p_card_id`) já existe e está correto (12-03) — ele só era inalcançável para homônimos porque a precedência conta-primeiro decidia antes. Esta correção o torna alcançável.

Purpose: WRITE-01 (lançar no destino certo) + HONEST-01 (não escolher silenciosamente o alvo errado; desambiguar).
Output: `api/assistant.js` com `tipo_destino` + regra de prompt; `assets/fides-claude.jsx` com resolução por tipo + desambiguação.
</objective>
