| client → Postgres (goals) | Escrita de image_url atravessa a fronteira; RLS é o guarda |
| unauth público → Storage (read) | Leitura pública de capas (não sensíveis) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering/Elevation | storage.objects INSERT | mitigate | RLS WITH CHECK `(storage.foldername(name))[1] = auth.uid()::text` rejeita upload em pasta de outro usuário |
| T-08-02 | Tampering/DoS | storage.objects UPDATE/DELETE | mitigate | Mesma checagem de prefixo owner nas policies de update/delete |
| T-08-03 | DoS | bucket goal-covers | mitigate | `file_size_limit = 5242880` (5MB) no bucket rejeita oversize server-side |
| T-08-04 | Tampering/XSS | bucket goal-covers | mitigate | `allowed_mime_types` (jpeg/png/webp) checa Content-Type real; capas só renderizadas como background-image/img src (nunca dangerouslySetInnerHTML) |
