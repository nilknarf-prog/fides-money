<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated (client SDK) → Postgres RPC | Qualquer usuário logado pode tentar `supabase.rpc('admin_*')` diretamente do console do browser |
| service_role (api/admin.js) → Postgres | Único caminho legítimo para as RPCs admin; ignora RLS/column-privileges por design |
| leitor de audit → admin_audit_log | Dados pessoais de terceiros (e-mail, before/after de plan) — só service_role pode ler |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-01 | Elevation of Privilege | admin_set_plan / admin_list_accounts | critical | mitigate | REVOKE EXECUTE FROM public, anon, authenticated + GRANT só a service_role, pela assinatura exata (M8/Pitfall 1). Testado: execução como authenticated falha com permission denied for function |
| T-16-02 | Spoofing / EoP | admin_set_plan confia em p_admin_id/p_admin_email | high | mitigate | GRANT exclusivo a service_role → único chamador é api/admin.js pós-guard; sem caminho para authenticated injetar os params (a RPC nem é executável por ele). NÃO usar auth.uid() (NULL sob service_role, Pitfall 3) |
| T-16-03 | Information Disclosure | admin_audit_log legível/adulterável por não-admin | high | mitigate | RLS on + zero policies + REVOKE ALL FROM anon, authenticated (V7.3). Minimização LGPD: list_accounts retorna só agregados/contagens, nunca lançamentos individuais |
| T-16-04 | Tampering | trava 13-02 (profiles.plan column privileges) | high | mitigate | Nenhum REVOKE/GRANT de profiles é alterado; admin muta plan via RPC SECURITY DEFINER (service_role ignora column-privilege por design, não por falha). Verificado por diff/introspecção |
| T-16-SC | Tampering (supply chain) | dependências npm/pip/cargo | low | accept | Sem novos pacotes nesta fase — reutiliza @supabase/supabase-js já em package.json (VERIFIED no registry, RESEARCH §Package Legitimacy Audit). Nenhum install task |
